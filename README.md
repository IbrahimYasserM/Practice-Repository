# Git & GitHub Practice Repo

Welcome! This repo exists for one reason: to give you a **safe, low-stakes place**
to practice the full open-source contribution workflow before you make your
first real contribution.

By the end of this task you will have:
- Forked and cloned a repo
- Read and followed a `CONTRIBUTING.md` like a real project would expect
- Created a branch, made a change, and committed it properly
- Hit and resolved a real merge conflict
- Opened a pull request using a PR template
- Answered reflection questions that prove you actually understood what you did (not just copy-pasted commands)

## Where to start

1. Read [`CONTRIBUTING.md`](./CONTRIBUTING.md) fully before doing anything else.
2. Check the **Issues tab** for the task assigned to you (labeled `good-first-task`) — it links to [`docs/TASK.md`](./docs/TASK.md) with the full instructions.
3. Answer questions as you go in [`QUESTIONS.md`](./QUESTIONS.md).
4. When you're done, open a PR using the template in [`.github/PULL_REQUEST_TEMPLATE.md`](./.github/PULL_REQUEST_TEMPLATE.md).

Good luck — treat this exactly like a real open source project. Read carefully,
follow the conventions, and don't skip the reflection questions.
