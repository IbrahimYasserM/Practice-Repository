## What is Open Source?
- Free & public software, large number of contributors and large codebase.

## Benefits of Open-Source Contribution
- CV leverage.
- Being able to navigate large codebases.
- High impact on the product you are contributing to.
- Exposure to real workplace workflows.
- Build connections with a variety of different people.

## Open-Source Programs
- Igalia.
- GSoC.
- LFX.
- OLFx.

## GSoC — Google Summer of Code
- Starts from late February – March.
- Open-source companies provide projects, and then you build a proposal, upload your CV, and wait to be accepted.
- Each project has a direct mentor.
- Projects can be:
  - Small (2 months).
  - Medium (3 months or more).
  - Large.

## LFX
- 3-month-long program.
- Opens thrice a year.
- Has many organizations under foundations; under these are companies.
- Has interviews.
- Not necessary to understand every part of the code; focus on understanding the feature you want to work on.
- Improves communication skills with people from all different countries and improves English skills.

### Prerequisites
- Good programming skill with a certain language.
- Git and GitHub.
- Basic skills in the field that you're applying in.

## Early Start
- Early start is better during this time (September – November), before midterms and heavier uni load, to focus on starting contributing.

## Mentorship Program
- Start with basics, Git/GitHub and basic programming.
- Mentors with experience will be assigned.
- Scale up progressively in order to prepare for contributing.

## Active Courses Server
- Active Courses server has a similar mentorship program focused on GSoC and many general channels.
