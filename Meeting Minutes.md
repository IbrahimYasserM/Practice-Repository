1# what is open source? 

open source is free software that has a lot of people involved in and made many contributions to build and maintain features as many users use these features.



2# why is it good to contribute?

it will be great for your cv as it shows you had made features that many users use it and the fact you made a feature that has been merged to the other features and code.
it will give a great amount of technical skills as you will always navigate through massive code files and there will be guidelines for your code to be accept , let's say one of them is to write clean code so this will lead you to learn how to write clean code and get used to always write clean code and this will make you work professionally.
  it will give a global network , you work with people  from different countries with different cultures so you make a global network and some open source companies doesn't usually open hiring but they hire people who made contributions with their software.
